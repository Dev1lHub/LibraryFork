# D3v1lHub

D3v1lHub is a **private, personal project** of its owner (GitHub: Dev1lHub): a custom Roblox UI library written in Luau.

> **This is not an open-source project.** All rights reserved. The code in this repository may not be used, copied, modified or redistributed by anyone except the owner. See [LICENSE](LICENSE).

## What's in here

| File | Purpose |
| --- | --- |
| `D3v1lLoader.lua` | Entry point. Detects the device (PC or mobile), shows the Yes/No window and loading screen, and loads only the matching library. |
| `PCGUILib.lua` | Full menu for PC / laptop. |
| `MobileGUILib.lua` | Slim touch menu for phones / tablets. |
| `Examples/` | Example scripts (`ExamplePC.lua`, `ExampleMobile.lua`) and `documentation.lua`. |
| `LICENSE` | Proprietary license (all rights reserved). |
